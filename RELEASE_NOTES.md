# Release Notes — Release Checklist

Short checklist used to verify a release pull request before it lands on `main`.

- [ ] Update `RELEASE_NOTES.md` with version number, date, and summary of changes
- [ ] Confirm all required tests pass on the PR's CI status
- [ ] Request at least one reviewer comment review before merging
- [ ] Verify the changelog and version bump are consistent across the checklist and docs
- [ ] Record the merge commit SHA and link the PR in the release tracker
